# Тестовое задание — сервис форм Forma

Публичный GitHub-репозиторий:

https://github.com/mellorine1337-crypto/forma-career-mvp

## Запуск

Требуется Node.js 20 или новее. Из корня проекта:

```bash
npm install
npm start
```

После запуска сервис доступен по адресу:

http://localhost:3000

Административная панель:

http://localhost:3000/admin

Внешние API, облачные сервисы и отдельно устанавливаемая база данных не используются. Данные сохраняются локально в `data/store.json`.
