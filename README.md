# Forma

Автономный MVP сервиса форм отклика для карьерной платформы. Менеджер собирает и публикует форму, студент отправляет отклик, а менеджер видит ответы и базовую конверсию.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm start
```

Откройте [http://localhost:3000/admin](http://localhost:3000/admin). Порт можно изменить: `PORT=4000 npm start`.

## Возможности

- конструктор семи типов полей;
- черновики, публикация и уникальные публичные ссылки;
- серверная валидация обязательных полей и email;
- просмотр ответов и экспорт CSV;
- воронка просмотров, начатых заполнений и отправок;
- локальное JSON-хранилище без внешних сервисов.

Данные сохраняются в `data/store.json`. Авторизация намеренно не включена в MVP согласно условию задания.
