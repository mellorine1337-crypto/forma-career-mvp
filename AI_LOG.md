# AI development log

Проект создан в совместной сессии с OpenAI Codex 21 октября 2026 года.

## Исходный запрос

Разработать MVP сервиса форм: менеджер создаёт форму в `/admin`, публикует её по уникальной ссылке, студент отправляет ответы, менеджер просматривает результаты. Обязательные ограничения: Node.js 20+, запуск через `npm install` и `npm start`, порт 3000 с поддержкой `PORT`, отсутствие внешних сервисов и СУБД.

## Принятые решения с помощью AI

- Выбран минимальный стек Node.js + Express + vanilla HTML/CSS/JS, чтобы снизить риск проблем при проверке.
- Данные сохраняются атомарно в `data/store.json`; отдельная СУБД не требуется.
- Помимо ключевого сценария добавлены серверная валидация, CSV-экспорт и простая аналитика воронки.
- Авторизация, загрузка файлов и условная логика вопросов осознанно исключены из MVP.
- Выполнен API smoke-test полного сценария и визуальная проверка интерфейса в браузере.

Полная история промптов и действий сохранена в исходном чате Codex и доступна для демонстрации на интервью.
